# Release automation

The publish workflow in `.github/workflows/release.yml` runs on manual dispatch or a push to `release`.

It installs npm dependencies and Rust stable, caches Rust artifacts, and invokes `tauri-apps/tauri-action@v1`. Checkout and Node setup use v7; Node's version is read from `engines.node` in `package.json`, as in CI. The matrix builds macOS Apple Silicon, macOS Intel, Ubuntu 22.04 and Windows bundles. Ubuntu installs WebKitGTK, AppIndicator, librsvg and patchelf first.

The action uses the workflow's `GITHUB_TOKEN` with `contents: write`. It creates a draft GitHub release using `app-v__VERSION__` and the configured application version. A successful local frontend build does not prove this release pipeline passes. Bootstrap did not dispatch the workflow or publish a release.

Tauri action v1 includes the version in `.app.tar.gz` asset names. With `releaseDraft: true`, rerunning against an already published release fails; use a new app version for the next release.
